# Security Policy

## BELISARIUS13 Security

BELISARIUS13 is a public cybersecurity engineering portfolio and security research lab operated by Joseph Daniel.

Security issues affecting the portfolio, its source repository, or its deployment configuration should be reported responsibly.

## Supported Scope

Security reports may include issues affecting:

- `https://belisarius13.com`
- this GitHub repository
- the GitHub Pages deployment configuration
- BELISARIUS13-owned website assets and configuration
- accidental exposure of sensitive information within this repository

## Reporting a Vulnerability

Please use **GitHub Private Vulnerability Reporting** for security-sensitive findings.

Do not disclose a vulnerability through a public GitHub issue if the report contains:

- exploitation details
- credentials or secrets
- sensitive configuration
- personally identifiable information
- information that could materially increase risk before remediation

Provide enough information to reproduce and understand the issue, including where applicable:

- affected URL, file, or component
- description of the issue
- reproduction steps
- observed impact
- suggested remediation
- supporting evidence

## Testing Guidelines

Good-faith security research should remain non-destructive.

Do not perform:

- denial-of-service or resource-exhaustion testing
- destructive modification of data
- social engineering
- credential attacks
- automated high-volume scanning
- attacks against third-party infrastructure or services
- attempts to access information unrelated to demonstrating the reported issue

Testing should stop once sufficient evidence has been collected to demonstrate the issue.

## Third-Party Services

The following are outside the direct security scope of BELISARIUS13:

- GitHub infrastructure
- GitHub Pages infrastructure
- Cloudflare infrastructure
- internet service providers
- external services or dependencies not operated by BELISARIUS13

Issues affecting those services should be reported to their respective operators.

## Disclosure

Reasonable effort will be made to review valid security reports, investigate their impact, and implement appropriate remediation.

Please allow time for investigation and remediation before public disclosure.
