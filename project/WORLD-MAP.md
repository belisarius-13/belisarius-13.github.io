# World map asset

Source: Natural Earth 1:110m land polygons, public-domain map data.
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Converted to a local equirectangular SVG with Antarctica omitted for a decorative background. Motion is decorative and does not represent live attacks or telemetry. No runtime map service or tracking request is used.
